# Scorpionism in Maranhão (2013–2024)

This repository contains the dataset supporting the article:

**Spatial and Temporal Patterns of Scorpionism in Maranhão, Brazil, 2013–2024**

## Overview

This repository provides the dataset used in the analyses of scorpionism in the state of Maranhão, Brazil, from 2013 to 2024.

## Repository Structure

```
data/
    scorpionism_maranhao_2013_2024.xlsx
```

## Data Source

The dataset was compiled from official Brazilian public databases, including:

- SINAN (Sistema de Informação de Agravos de Notificação)
- IBGE (Instituto Brasileiro de Geografia e Estatística)
