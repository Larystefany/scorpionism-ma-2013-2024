# Dataset: Scorpionism in Maranhão (2013–2024)

This repository contains the dataset supporting the article:

**Spatial and Temporal Patterns of Scorpionism in Maranhão, Brazil, 2013–2024**

## Overview

This repository provides the dataset used in the analyses of scorpionism in the state of Maranhão, Brazil, from 2013 to 2024.

## Dataset description

The dataset is organized at the municipality-year level, where each row represents a municipality in a given calendar year. Variables include the municipality identification code (IBGE), municipality name, year of observation, number of reported scorpionism cases, resident population, and the geographic coordinates of the municipality centroid.

## Repository Structure

- **data/dataset_scorpionism_maranhao_2013_2024.xlsx** – Dataset used in all statistical and spatial analyses.
- **data/data_dictionary.xlsx** – Description of the variables, formats, and units included in the dataset.

## Data Source

The dataset was compiled from official Brazilian public databases, including:

- SINAN (Sistema de Informação de Agravos de Notificação)
- IBGE (Instituto Brasileiro de Geografia e Estatística)

## Study area

State of Maranhão, northeastern Brazil.

## Study period

2013–2024.
